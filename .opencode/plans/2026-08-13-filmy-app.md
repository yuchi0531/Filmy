# Filmy - 映画館スケジュール検索アプリ 実装計画

## 概要

Filmarks（フィルマークス）をスクレイピングし、近隣映画館の上映スケジュールを検索・表示するMaterial 3 Androidアプリ。バックエンドAPI（FastAPI on Koyeb）がスクレイピングを担当し、AndroidアプリはREST APIを叩く。モノレポ構成。各段階で監査ゲートを設ける。

## アーキテクチャ

```
[Filmarks Website]
    ↓ BeautifulSoup スクレイピング
[Koyeb Backend: FastAPI + cachetools]
    ↓ REST API (JSON)
[Android App (Kotlin + Compose + Material 3)]
```

## 技術スタック

### バックエンド（Koyeb）
- **言語:** Python 3.12
- **フレームワーク:** FastAPI
- **スクレイピング:** BeautifulSoup4 + lxml
- **キャッシュ:** cachetools（メモリ内、常駐プロセス前提）
- **デプロイ:** Docker → Koyeb（無料常駐インスタンス）
- **無料枠:** 1VM (shared-cpu-1x, 256MB) + 160GB帯域/月

### Androidアプリ
- **言語:** Kotlin
- **UI:** Jetpack Compose + Material 3
- **HTTP:** Retrofit + OkHttp
- **データ永続化:** Room（お気に入り + キャッシュ）
- **画像読み込み:** Coil
- **ナビゲーション:** Compose Navigation
- **位置情報:** FusedLocationProviderClient
- **非同期:** Kotlin Coroutines + Flow

## バックエンドAPI仕様

### APIエンドポイント

| Method | Path | 説明 | ソース |
|---|---|---|---|
| GET | `/api/movies/now` | 上映中映画一覧 | `/list/now` |
| GET | `/api/movies/coming` | 公開予定映画一覧 | `/list/now` |
| GET | `/api/movies/upcoming` | 今週公開映画一覧 | `/list/upcoming` |
| GET | `/api/movies/trend` | トレンド映画一覧 | `/list/trend` |
| GET | `/api/movies/{movie_id}` | 映画詳細 | `/movies/{id}` |
| GET | `/api/movies/{movie_id}/reviews` | 映画レビュー | `/movies/{id}/reviews` |
| GET | `/api/search?q={query}` | 映画検索 | `/search/movies?q=` |
| GET | `/api/theaters/{prefecture}` | 都道府県別劇場一覧 | `/theaters/{pref}` |
| GET | `/api/theaters/{prefecture}/{area_id}` | エリア別劇場一覧 | `/theaters/{pref}/{area}` |
| GET | `/api/theaters/{prefecture}/{area_id}/{theater_id}` | 劇場詳細+スケジュール | `/theaters/{pref}/{area}/{id}` |
| GET | `/api/theaters/nearby?lat={lat}&lng={lng}` | 近隣劇場検索 | 座標DB検索 |

### キャッシュ戦略

| データタイプ | キャッシュ時間 | 理由 |
|---|---|---|
| 映画一覧（上映中等） | 6時間 | 日中変化少ない |
| 映画詳細 | 24時間 | 基本変わらない |
| 劇場スケジュール | 1時間 | 曜日で変化 |
| 近隣劇場リスト | 24時間 | 劇場データは固定 |
| 検索結果 | 1時間 | キャッシュしにくい |

# デプロイ手順

### Koyebデプロイ
```bash
curl -fsSL https://raw.githubusercontent.com/koyeb/cli/master/install.sh | sh
koyeb login
cd backend && koyeb app create filmy && koyeb service create filmy --docker . --port 8080
koyeb secret create ...
```

### Androidビルド
```bash
cd app && ./gradlew assembleRelease
# app/build/outputs/apk/release/app-release.apk
```

# 注意事項

1. **スクレイピング間隔**: Filmarksへのアクセスは最低5秒間隔
2. **User-Agent**: 正常なブラウザからのアクセスを装う
3. **キャッシュ**: 積極的にキャッシュし、Filmarksへの負荷を軽減
4. **エラーハンドリング**: ネットワーク・パースエラーに備える
5. **利用規約**: 技術実証目的。外部公開は避ける
6. **Koyeb無料枠**: 512MB/0.1vCPU/2GB 24/7常駐。クレジットカード必要。監視は必要
